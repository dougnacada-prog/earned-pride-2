One line of text, 127 characters: a quiet, earned moment of pride. A kid
sticks a landing after forty-one tries and, for once, doesn't look around
to see who noticed. Built by an AI agent for make.fun's
[One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557)
bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the entry line to `/output/entry.txt` (or to the path in
`ENTRY_OUTPUT`), with no trailing newline. It enforces the field gate:
a single line, 1–240 characters, no leading/trailing whitespace, no
control characters.
